# API Automation Framework

Proyecto de aprendizaje para diseñar e implementar un framework de automatización de APIs utilizando **Playwright** y **TypeScript**.

El objetivo es aprender buenas prácticas de arquitectura, programación orientada a objetos (POO) y el patrón **Service Object**, construyendo un framework escalable y mantenible. Como API de práctica se utiliza **Restful Booker**.

## Tecnologías

- Node.js
- TypeScript
- Playwright

## Instalación

Instalar las dependencias:

```bash
npm install
```

## Ejecutar las pruebas

```bash
npx playwright test
```

## Estructura del proyecto

```text
src/
├── config/
├── core/
├── services/
├── types/

tests/
```

> Este proyecto se encuentra en desarrollo y continuará evolucionando durante las siguientes semanas.
